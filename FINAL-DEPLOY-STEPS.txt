================================================================================
TROUBLESHOOTING
================================================================================

Problem: Can't create template folder
Solution: Make sure you're in /public_html/portal/ directory

Problem: Upload fails
Solution: Check file size limits in cPanel (should be fine for these files)

Problem: 404 error when visiting URL
Solution:
  - Check files are in correct location: /public_html/portal/template/
  - Check file names are lowercase: index.php and submit.php
  - Check file permissions (should be 644)

Problem: PHP errors displayed
Solution: Both files are complete and tested - if errors occur, check PHP version
          (Files work with PHP 7.4+)
